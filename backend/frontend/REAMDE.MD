# Explainable AI Mental Health Platform

An AI-powered mental health analysis web application using:

- NLP
- Voice Emotion Detection
- Facial Emotion Recognition
- Explainable AI

## Features

- Text sentiment analysis
- Voice emotion analysis
- Facial emotion detection
- Mental health prediction

## Tech Stack

- Python
- FastAPI
- Streamlit
- Transformers
- OpenCV
- Librosa

## Run Backend

cd backend

uvicorn main:app --reload

## Run Frontend

cd frontend

streamlit run app.py
